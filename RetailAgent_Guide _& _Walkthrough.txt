# RetailAgent Demo Guide &  Walkthrough

# 1. Project Startup

## Step 1: Open Terminal

Navigate to the project folder:

```bash
cd RetailAgent
```

---

## Step 2: Activate Virtual Environment

Windows

```bash
venv\Scripts\activate
```

Linux/Mac

```bash
source venv/bin/activate
```

---

## Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Step 4: Configure Environment Variables

Create `.env`

```
GROQ_API_KEY=your_groq_api_key
```

---

## Step 5: Create Vector Database (Only Once)

```bash
python -m src.rag.ingest
```

This:

* Loads knowledge base documents
* Splits into chunks
* Generates embeddings
* Stores vectors in ChromaDB

No need to run every time unless knowledge base changes.

---

## Step 6: Start API

```bash
uvicorn src.api.app:app --reload
```

Server starts:

```
http://127.0.0.1:8000
```

Swagger UI:

```
http://127.0.0.1:8000/docs
```

# 6. How to Explain RAG

Without RAG

LLM answers from pre-trained knowledge.

May hallucinate.

With RAG

Retriever fetches company documents.

LLM answers only using retrieved context.

Benefits:

* Grounded
* Updatable
* Lower hallucination
* No retraining required

---

# 7. Why ChromaDB?

Stores vector embeddings.

Supports semantic similarity search.

Example:

"refund policy"

and

"return policy"

produce similar vectors.

Retriever can find both.

# 12. Interview Explanation (2 Minutes)

"I built an Agentic AI Retail Customer Retention Copilot.

The system predicts customer churn using a Random Forest model trained on RFM features.

Instead of stopping at prediction, it uses Retrieval-Augmented Generation.

Business policies are stored as documents and converted into embeddings using HuggingFace Sentence Transformers.

These embeddings are stored inside ChromaDB.

When a customer is predicted as High Churn, LangGraph orchestrates multiple agents.

The Churn Agent predicts the risk.

The RAG Agent retrieves the most relevant retention policies.

Groq LLM generates a grounded recommendation using only the retrieved context.

The Recommendation Agent combines prediction and knowledge retrieval into an actionable business recommendation.

The entire workflow is exposed through FastAPI and demonstrated through Swagger UI."

# 14. How to Update Company Policies

Simply add or edit Markdown files inside:

knowledge_base/

Run:

```bash
python -m src.rag.ingest
```

Embeddings are regenerated.

No model retraining required.
